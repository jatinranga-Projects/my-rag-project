# 🤖 Universal RAG Chatbot

A professional-grade Retrieval-Augmented Generation (RAG) application that allows users to upload PDF, CSV, or Excel files and chat with them in real-time.

## 🌟 Features
- **Dynamic Upload:** Swap documents instantly via the sidebar.
- **Multi-Format Support:** Handles `.pdf`, `.csv`, and `.xlsx`.
- **Advanced RAG:** Powered by LangChain, OpenAI (GPT-4o), and ChromaDB.
- **Web Interface:** Built with Gradio for a smooth user experience.

## 🛠️ Tech Stack
- **Language:** Python 3.11
- **Orchestration:** LangChain
- **LLM:** OpenAI GPT-4o
- **Vector Database:** ChromaDB
- **UI:** Gradio
